## Binary Number Representation

Decimal 75 to Binary:
- 75 ÷ 2 = 37 remainder 1
- 37 ÷ 2 = 18 remainder 1
- 18 ÷ 2 = 9 remainder 0
- 9 ÷ 2 = 4 remainder 1
- 4 ÷ 2 = 2 remainder 0
- 2 ÷ 2 = 1 remainder 0
- 1 ÷ 2 = 0 remainder 1
Reading remainders bottom-to-top: 75 = 1001011

Binary 110101 to Decimal:
- (1 × 2^5) + (1 × 2^4) + (0 × 2^3) + (1 × 2^2) + (0 × 2^1) + (1 × 2^0)
- 32 + 16 + 0 + 4 + 0 + 1 = 53

Computers use binary internally because hardware circuits operate using two stable voltage states (ON = 1 and OFF = 0), which makes data storage and processing reliable.
